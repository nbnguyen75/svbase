`NumberField.Input` is a `role="spinbutton"` textbox with `aria-valuenow/min/max`; it parses on commit (change, blur, Enter) and reverts invalid text. `Increment`/`Decrement` step within bounds and disable themselves at the edges. Pairs with `Field` for label, description, and custom validation.

## Keyboard interactions

- `↑` `↓` step by `step`; `PgUp` / `PgDn` step by `largeStep`.
- `Home` / `End` jump to min/max (when bounded).
- `Enter` commits the typed text.
