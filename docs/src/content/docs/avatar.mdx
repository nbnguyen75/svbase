## Anatomy

```svelte title="App.svelte"
<script>
	import { Avatar } from 'svbase';
</script>

<Avatar.Root>
	<Avatar.Image src="/me.png" alt="Me" />
	<Avatar.Fallback>ME</Avatar.Fallback>
</Avatar.Root>
```

`Avatar.Root` renders a `span` carrying `data-status` (`idle`, `loading`, `loaded`, `error`) for styling. The image hides itself until loaded; cached images resolve synchronously at mount.

## Keyboard interactions

- None — avatars are never focusable. The image needs an `alt`, the fallback needs readable text.
