Labelled fields with native constraint validation, custom validators, and a submit-collecting form wrapper.

<FormDemo client:visible />

## Anatomy

```svelte title="App.svelte"
<script>
  import { Field, Form } from 'svbase';
</script>

<Form.Form
  onFormSubmit={(values, errors) => {
    if (Object.keys(errors).length === 0) save(values);
  }}
>
  <Field.Root name="email">
    <Field.Label>Email</Field.Label>
    <Field.Control type="email" required />
    <Field.Description>We never share it.</Field.Description>
    <Field.Error />
  </Field.Root>
  <button type="submit">Save</button>
</Form.Form>
```

`Field.Label`, `Field.Control`, `Field.Description`, and `Field.Error` link to the control through a generated id (`aria-describedby` includes the description always, the error only while invalid). `Field.Control` renders an `Input` bound to the field; use `Input` directly for standalone or custom-wired inputs. `Fieldset.Root` groups fields and disables them together, with `Fieldset.Legend` as its caption.

## Keyboard interactions

- `Tab` moves through labels, controls, and buttons natively; `Enter` submits from any control.
- A failed submit focuses the first invalid control.
- `required` empty values stay quiet until the field is changed — submit always flags them.
