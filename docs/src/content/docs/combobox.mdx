Filterable single-select with a text input and listbox popup. With `freeInput` it becomes a free-text autocomplete.

## Anatomy

```svelte title="App.svelte"
<script>
  import { Combobox } from 'svbase';
</script>

<Combobox.Root name="fruit">
  <Combobox.Input aria-label="Fruit" />
  <Combobox.Portal>
    <Combobox.Content>
      <Combobox.Item value="apple">Apple</Combobox.Item>
      <Combobox.Item value="banana">Banana</Combobox.Item>
      <Combobox.Empty>No matches</Combobox.Empty>
    </Combobox.Content>
  </Combobox.Portal>

```

`Combobox.Input` is a `role="combobox"` textbox tracking `aria-expanded`, `aria-controls`, and `aria-activedescendant`. `Combobox.Item` takes `value`, an optional `label` (defaults to its text), and `disabled`. `Combobox.Group` + `Combobox.GroupLabel` cluster items; `Combobox.Empty` shows when the filter matches nothing. `Combobox.Trigger` toggles the list without stealing input focus.

## Keyboard interactions

- `↓` `↑` open the list (when closed) and move the highlight; `Home` / `End` jump.
- `Enter` commits the highlighted item — or the typed text in `freeInput` mode.
- `Esc` closes and reverts to the selected label (strict mode); `Tab` closes the same way.
- Focus stays in the textbox while navigating; screen readers follow `aria-activedescendant`.
