Whole-group `disabled` freezes every item. One tab stop per group: checked item first, otherwise the first enabled item. Hidden-input sync honors `required` (blocks submit until checked) but a group-level `disabled` drops the input the way native fieldsets do.

## Keyboard interactions

- `Tab` enters the group at the checked item (or first enabled); arrows move and select.
- `Space` selects the focused item (already-selected semantics included).
