## Anatomy

```svelte title="App.svelte"
<script>
	import { ToggleGroup } from 'svbase';
</script>

<ToggleGroup.Root bind:value={align} name="align">
	<ToggleGroup.Item value="left">Left</ToggleGroup.Item>
	<ToggleGroup.Item value="center">Center</ToggleGroup.Item>
</ToggleGroup.Root>
```

`ToggleGroup.Item` takes a unique `value` and renders a `Toggle` bound to the group — arrows travel with a single tab stop, and `data-pressed` marks the active items for styling.

## Keyboard interactions

- `←` `→` move focus between items (vertical orientation: `↑` `↓`); `Home` / `End` jump.
- `Enter` and `Space` flip the focused item.
