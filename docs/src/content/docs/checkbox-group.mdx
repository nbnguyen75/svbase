## Anatomy

```svelte title="App.svelte"
<script>
	import { CheckboxGroup } from 'svbase';
</script>

<CheckboxGroup.Root bind:value={toppings} name="topping" allValues={['cheese', 'pepperoni']}>
	<CheckboxGroup.Parent>All toppings</CheckboxGroup.Parent>
	<CheckboxGroup.Item value="cheese">Cheese</CheckboxGroup.Item>
	<CheckboxGroup.Item value="pepperoni">Pepperoni</CheckboxGroup.Item>
</CheckboxGroup.Root>
```

`CheckboxGroup.Parent` checks or clears everything, showing mixed state for partial selection. `CheckboxGroup.Item` takes a unique `value`. Put `name` on the root only — one hidden input per selected value submits the group.

## Keyboard interactions

- `Space` toggles the focused box; `Enter` never toggles (it submits the form).
