Scalar gauge with low/high bands. The steady sibling to progress bars — no animation, just the measurement.

<MeterDemo client:visible />

## Anatomy

```svelte title="App.svelte"
<script>
	import { Meter } from 'svbase';
</script>

<Meter.Root value={72} min={0} max={100} ariaLabel="Storage used">
	<Meter.Track>
		<Meter.Indicator />
	</Meter.Track>
	<Meter.Value />
</Meter.Root>
```

`Meter.Track` frames the bar, `Indicator` fills by percent, `Label` names it, and `Value` prints the formatted reading.

## Keyboard interactions

- None — meters are read-only indicators, never focusable.
