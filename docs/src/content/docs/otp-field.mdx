The first segment carries `autocomplete="one-time-code"` for mobile SMS autofill. Pair with `Field` and a length-checking `validate` for required codes.

## Keyboard interactions

- Typing a character commits it and advances; `←` `→` move between segments.
- `Backspace` on an empty segment backs up and clears the previous one; `Delete` clears in place.
- Pasting distributes filtered characters from the focused segment.
