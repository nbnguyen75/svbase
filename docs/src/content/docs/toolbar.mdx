## Anatomy

```svelte title="App.svelte"
<script>
  import { Toolbar } from 'svbase';

<Toolbar.Root>
  <Toolbar.Button>Save</Toolbar.Button>
  <Toolbar.Separator />
  <Toolbar.Link href="/help">Help</Toolbar.Link>
  <Toolbar.Input aria-label="Search" />
</Toolbar.Root>
```

`Toolbar.Button`, `Toolbar.Link`, and `Toolbar.Input` register for roving; `Group` clusters controls; `Separator` divides without ever taking focus. Buttons and links share one tab stop; the input stays tabbable with native caret keys.

## Keyboard interactions

- `←` `→` move focus between controls (vertical orientation: `↑` `↓`); `Home` / `End` jump.
- Disabled controls are skipped by arrows; inputs keep arrow keys for the caret.
